# SikkatuCAD

[English](README.md) | [中文](README.zh.md)

![SikkatuCAD](app/src/main/res/drawable/ic_sikkatu_logo.png)

Мобильный редактор и просмотрщик чертежей CAD для Android. Работает с файлами **DXF** и **DWG**.
Интерфейс: русский / English / 中文.

## Возможности

- **Открытие и просмотр** чертежей DXF / DWG (фасады, планы, разрезы);
- **Перевод надписей** (TEXT / MTEXT / ATTRIB) с русского на английский и тайский:
  экспорт текстов в JSON → перевод → импорт обратно в чертёж;
- **Сохранение** изменённых чертежей в DXF (надёжно) или DWG (экспериментально);
- Замеры: расстояние, угол, площадь; авто-размеры;
- Редактирование геометрии: линия, прямоугольник, окружность, дуга, полилиния, текст;
- Управление слоями, экспорт вида в PNG.

## Приватность

Приложение **не отправляет данные в интернет**. Все операции с чертежами происходят локально на устройстве.
Это можно проверить — весь исходный код в этом репозитории.

## Сборка

```bash
git clone https://github.com/sikkatu/SikkatuCAD.git
./gradlew assembleDebug
```

Нативный движок DWG (Rust):

```bash
cd rust-bridge
cargo build --release --target aarch64-linux-android --lib
```
